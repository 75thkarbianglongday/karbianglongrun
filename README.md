# Karbi Anglong Run Fest 2026

**75th Karbi Anglong Day Open Marathon**  
Organised by: Sports & Youth Welfare Department, KAAC  

**Tagline:** One Land. One Spirit. One Run.

## Overview

Self-contained registration portal for the Karbi Anglong Run Fest 2026 / 75th Karbi Anglong Day Open Marathon.

### Features
- Categories: Men’s Open & Women’s Open
- Full registration form (Name, DOB, Gender, Category, Phone, Address, Emergency Contact, Blood Group, T-shirt size, Medical info)
- Automatic Registration ID generation (`KARF2026-XXXX`)
- Data stored in browser (`localStorage`)
- Admin panel to view registrations + Export to CSV
- Printable confirmation after successful registration
- Success / error popup modals
- Left-side red, white, and black vertical stripe
- Primary colour: `#2563eb`

### Admin Access
- Password: `kaac2026`

## Files
- `index.html` — Main registration portal (open this in a browser or host via GitHub Pages)

## Usage
1. Open `index.html` in any modern browser.
2. Fill and submit the registration form.
3. Use the Admin Panel button (password: `kaac2026`) to view or export registrations.

## Notes
- All data is stored locally in the browser (no server required).
- For production use with a backend, additional server-side storage would be needed.
- Official logos and cutout images can be added by replacing the placeholder elements in the hero section.
